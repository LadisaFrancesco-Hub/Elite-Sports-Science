# Elite Sports Science — CLAUDE.md

## Aggiornamento progresso
Alla fine di ogni sessione o task completato, aggiorna `.claude/PROGRESS.md` con cosa è stato fatto e qual è il prossimo passo.

## Scrittura schede di allenamento
Prima di **creare o modificare una scheda** (nel DB `schedules` o come bozza), leggi SEMPRE
`.claude/coaching/SCHEDE_STYLE.md`: contiene SOLO il "contenitore" — modello dati, stile di
scrittura degli esercizi/note e schema del campo `exercises` + workflow. NON contiene scelte di
programmazione (esercizi/serie/onde/metodologia): quelle sono diverse per ogni atleta e si
decidono caso per caso col coach. Mantieni quel file aggiornato quando emergono nuove
convenzioni di **scrittura/formato** (non di programmazione).
